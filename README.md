# Sonic Studio Client

The modern Next.js 14/15 frontend client for **Sonic AI**.
Engineered for multi-modal creative workflows: speech transcription, viral 9:16 short clips, kinetic subtitle editing, and generative AI filmmaking.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
```bash
cp .env.local.example .env.local
```

### 3. Start Development Server
```bash
npm run dev
# Serves on http://localhost:3000
```
